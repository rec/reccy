# reccy

Shared Python utilities for local command-line applications: configuration,
application lifecycle, IPC, service management, and runtime helpers.

The API Reference is generated from the source code. The guides describe
[shared features](shared-features.md), [porting consumers](porting.md),
[testing CLI help](testing-cli-help.md), and
[publishing documentation](documentation.md), and [releasing](releasing.md).
